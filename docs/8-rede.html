8  Leitura dos arquivos e montagem da rede

Medir acessibilidade exige saber quanto tempo se leva para ir de cada origem a cada destino, por cada modo de interesse. Esse cálculo depende de uma representação computacional da rede de transportes, montada a partir de arquivos de origens distintas. Este capítulo trata dos insumos, mostra onde cada um deve estar, constrói a rede multimodal de Anápolis com o r5r e produz a matriz de tempos de viagem que sustenta todo o restante da Parte 2.

NotaNesta seção você vai
  • identificar os insumos exigidos pelo r5r e a função de cada um
  • organizar os arquivos na estrutura de pastas esperada
  • construir a rede multimodal com setup_r5()
  • calcular a matriz de tempos de viagem por modo
  • inspecionar e validar os resultados antes de seguir adiante

8.1 Os insumos da rede

ImportanteOnde os arquivos devem estar

O r5r monta a rede a partir de uma única pasta, lendo todos os arquivos reconhecidos que encontrar nela. Coloque os insumos em dados/r5/ e não misture arquivos de cenários diferentes no mesmo diretório.

dados/r5/
├── anapolis.osm.pbf     rede viária (obrigatório)
├── anapolis_gtfs.zip    transporte coletivo (opcional)
└── anapolis_dem.tif     modelo digital de elevação (opcional)

8.4 Matriz de tempos de viagem

ttm <- travel_time_matrix(
  r5r_core,
  origins      = pontos,
  destinations = pontos,
  mode         = c("WALK", "TRANSIT"),
  departure_datetime = as.POSIXct("2026-09-09 07:00:00"),
  max_trip_duration  = 60
)

AvisoEncerre a sessão do R5

Ao terminar, chame stop_r5(r5r_core) para liberar a memória da máquina virtual. Sem isso, a JVM continua ocupando a RAM até o fim da sessão do R.
